## 数値計算のコード（付録B）

付録B「厳密対角化の数値計算」で用いた，横磁場イジング模型

$$H_{\rm Ising}(g) = -g^{-1}\sum_{j=1}^L Z_jZ_{j+1} - g\sum_{j=1}^L X_j$$

の厳密対角化のコードです．

| ファイル | 内容 |
|---|---|
| [`ising_ed.ipynb`](ising_ed.ipynb) | 説明つきの Jupyter ノートブック（付録Bの計算の全体） |
| [`ising_ed.py`](ising_ed.py) | 主要部分だけをまとめたスクリプト版 |

ノートブックでは次のことを行います．

1. $\mathbb{Z}_2$ 対称性 $\eta=\prod_j X_j$ の固有値（セクター）ごとの厳密対角化
2. クラマース＝ワニエ双対性 $g\leftrightarrow g^{-1}$ の数値的な確認（ねじれた境界条件を含む，第7章）
3. 付録Cのジョルダン＝ウィグナー変換による厳密解との比較
4. 低エネルギースペクトルとギャップの図（付録B・第6章の図）
5. 臨界点 $g=1$ でのギャップの有限サイズスケーリング
6. KW欠陥の位置によらないスペクトルの確認（第8章）

### 実行方法

必要なのは Python 3 と `numpy`，`scipy`，`matplotlib` だけです．

```sh
pip install numpy scipy matplotlib jupyter
jupyter notebook ising_ed.ipynb   # ノートブック版
python ising_ed.py               # スクリプト版
```

図は同じフォルダの `figures/` に PDF として出力されます．
